# 🐊 鳄鱼派量化 (croc-quant)

两套"鳄鱼"体系并排的量化看板：

**① 鳄鱼线系统**（比尔·威廉斯 Alligator）：像鳄鱼一样大部分时间空仓"趴着"
（配置国债ETF），趋势明确才出击。复刻 **招商证券《基于鳄鱼线的指数择时及
轮动策略》(2024-05)**：Alligator 三线为主信号，AO动量、分形突破、MACD
三个过滤器合成带粘性的满仓/空仓状态机。研报口径：沪深300择时年化~12%/
回撤16%，指数轮动~21%，空仓占比~80%。

**② 评分看板系统**（仿公众号「像鳄鱼一样思考」）：多因子加权给市场打
S/A/B/C 级——评级定仓位松紧（A/S 满仓动量最强宽基、B 半仓+半防守、
C 全躲三剑客）。因子：趋势宽度(鳄鱼线多头占比)、20日动量、量能、
价格宽度、两融趋势（数据源停更时自动剔除）。三剑客 = 红利ETF(高股息)/
黄金ETF(避险)/国债ETF(利率债) 三种逻辑等权。评分看板另附乐咕市场快照
与行业主力资金流排行。该体系确切配方在知识星球不公开，本实现为
公开数据的"神似"版本。

## 运行

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

打开 http://localhost:8501

## 四个页面

- **今日信号**：ETF池状态表 + 两套系统并排给出今日应持仓。
- **评分看板**：今日评级(S/A/B/C)与得分、因子分解、评分历史（评级底色）、
  市场快照（涨跌/停家数）、板块资金流排行、三剑客近况。
- **行情与鳄鱼线**：K线 + 颚/齿/唇三线 + 持仓区间底色 + AO/MACD 子图。
- **回测**：单标的择时（可拆信号）、ETF池轮动、评分看板策略三个标签页，
  含年化/回撤/夏普/卡玛/胜率/盈亏比。

## 信号规则

| 信号 | +1（看多） | -1（看空） |
|------|-----------|-----------|
| Alligator | 唇>齿>颚（多头） | 唇<齿<颚（空头） |
| AO | 连续3日上行 | 连续3日下行 |
| 分形 | 收盘破最近上分形高点 | 收盘破最近下分形低点 |
| MACD | 水上/零轴金叉 | 水下/零轴死叉 |

合成（满仓/空仓两态，带粘性）：
- **看多**：`Alligator=1 且 (分形=1 或 MACD=1)`
- **看空**：任一信号 = -1
- 其他：维持前一交易日仓位

T+1 成交假设（默认 T+1 开盘价，可选 T+1 收盘 / T 收盘），单边手续费可调。

## 结构

```
croc/
  data.py       多源数据层：东财(后复权)->baostock->新浪，parquet缓存
  indicators.py SMMA/Alligator/AO/分形/MACD
  strategy.py   四信号 + 合成状态机（含消融开关）
  rotation.py   ETF池轮动权重：等权 / 最强动量 + 国债腿
  board.py      评分看板：因子打分、S/A/B/C评级、评级驱动权重、三剑客、
                市场快照/板块资金流/两融数据接口
  backtest.py   T+1回测、绩效、逐笔交易统计
  universe.py   默认ETF池（宽基+国债ETF）与三剑客防守池
app.py          Streamlit 看板
data_cache/     本地数据缓存（自动增量更新）
```

## 注意

- A股 T+1、不可做空：信号只有 满仓/空仓 两态，空仓期配国债ETF。
- 数据源的"后复权"价格用于回测；行情页显示价与实价可能有因子差，收益序列不受影响。
- 东财接口对频繁请求会限流，已做退避重试 + 双源降级；实在不通时删 data_cache 重试。
- ⚠️ 仅供研究，不构成投资建议。实盘需自行接券商（QMT/PTrade），本软件只做信号与回测。
